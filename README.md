# 🎮 Універсальний ШІ-помічник для ігор

Веб-застосунок, який:

- 📷 **Аналізує скріншоти** гри (vision-моделі).
- 💬 **Відповідає на текстові питання** українською мовою.
- 📚 Використовує **перевірену інформацію з офіційних вікі** (підхід RAG).
- 🔗 **Дає посилання на джерела** до кожної відповіді.
- 🆓 Працює через **безкоштовних провайдерів ШІ** — **Groq** та **OpenRouter**.

### Підтримувані ігри

| Гра | Джерело (вікі) |
|-----|----------------|
| Hearts of Iron IV | heartsofiron.fandom.com |
| Minecraft | minecraft.wiki |
| Terraria | terraria.wiki.gg |
| Don't Starve Together | dontstarve.fandom.com |
| Albion Online | albion.wiki.gg |

> ℹ️ **Про джерела HoI4 та Albion.** Офіційні вікі цих ігор
> (`hoi4.paradoxwikis.com` і `wiki.albiononline.com`) закриті JS-перевіркою
> (Fastly / Cloudflare) і недоступні для серверних запитів. Тому помічник бере
> дані з доступних вікі спільноти. Вікі Albion на wiki.gg невелика й охоплює
> переважно предмети та лор — для глибоких питань про механіки помічник чесно
> позначить відповідь як неперевірену. Решта ігор використовують основні вікі.

## 🚀 Швидкий старт (Windows)

### 1. Отримайте безкоштовний ключ API

- **Groq** (рекомендовано, швидкий): https://console.groq.com/keys
- або **OpenRouter**: https://openrouter.ai/keys

### 2. Запустіть

Двічі клацніть **`start.bat`** — він сам створить середовище, встановить
залежності та запустить сервер.

Або вручну:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env      # за бажанням впишіть ключ у .env
python run.py
```

### 3. Відкрийте у браузері

http://127.0.0.1:8000

Вставте ключ API у бічну панель (зберігається лише у вашому браузері) — і
можна користуватися. Ключ також можна задати в `.env`.

## 🧠 Як це працює

```
Питання + скріншот
        │
        ▼
1. Планувальник (ШІ) ── визначає гру + формує англомовні пошукові запити
        │
        ▼
2. Пошук у вікі (MediaWiki API) ── перевірені витяги + канонічні URL
        │
        ▼
3. Відповідач (ШІ) ── відповідь українською ТІЛЬКИ за фактами з вікі,
                       з посиланнями [1], [2] …
```

Завдяки RAG модель не «вигадує» факти, а спирається на офіційну вікі та
завжди показує джерела.

## ⚙️ Налаштування (`.env`)

| Змінна | Призначення | За замовчуванням |
|--------|-------------|------------------|
| `AI_PROVIDER` | `groq` або `openrouter` | `groq` |
| `GROQ_API_KEY` | ключ Groq | — |
| `OPENROUTER_API_KEY` | ключ OpenRouter | — |
| `GROQ_TEXT_MODEL` | текстова модель Groq | `llama-3.3-70b-versatile` |
| `GROQ_VISION_MODEL` | vision-модель Groq | `meta-llama/llama-4-scout-17b-16e-instruct` |
| `OPENROUTER_TEXT_MODEL` | текстова модель OR | `meta-llama/llama-3.3-70b-instruct:free` |
| `OPENROUTER_VISION_MODEL` | vision-модель OR | `meta-llama/llama-4-scout:free` |
| `WIKI_TOP_K` | скільки статей вікі брати | `4` |
| `HOST` / `PORT` | адреса сервера | `127.0.0.1` / `8000` |

> Для аналізу скріншотів потрібна **vision-модель**. Якщо обрана модель не
> підтримує зображення — задайте іншу у відповідній змінній.

## ➕ Як додати нову гру

Відредагуйте [`backend/games.py`](backend/games.py) — додайте запис із
посиланням на `api.php` офіційної вікі (більшість вікі побудовані на
MediaWiki) та ключовими словами для авто-визначення. Більше нічого міняти не
треба.

## 📁 Структура

```
backend/
  config.py      налаштування / .env
  games.py       реєстр ігор та їхніх вікі
  wiki.py        пошук у MediaWiki + витяги + посилання
  providers.py   єдиний клієнт Groq / OpenRouter
  assistant.py   оркестрація RAG (планувальник + відповідач)
  main.py        FastAPI: API та роздача фронтенду
frontend/
  index.html, style.css, app.js   чат-інтерфейс
run.py           запуск сервера
start.bat        автоматичне налаштування + запуск (Windows)
check_wikis.py   перевірка доступності вікі (без ключа API)
```

## 🩺 Діагностика вікі

Якщо відповіді приходять без джерел — перевірте з'єднання з вікі (ключ API не
потрібен):

```powershell
venv\Scripts\activate
python check_wikis.py
```

Скрипт покаже, які вікі доступні (очікувано `5/5`).

## 🔒 Примітки

- Ключ API з інтерфейсу зберігається лише у `localStorage` браузера й
  надсилається тільки на ваш локальний сервер.
- Відповіді мають інформаційний характер; завжди перевіряйте за наданими
  посиланнями на вікі.
