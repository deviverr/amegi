Швидкий старт

Запускається локально на Windows за пару хвилин

# 1. Візьміть безкоштовний ключ API
#    Groq:       https://console.groq.com/keys
#    OpenRouter: https://openrouter.ai/keys

# 2. Клонуйте репозиторій
git clone https://github.com/deviverr/amegi.git
cd amegi

# 3. Запустіть (створить середовище й встановить залежності)
.\start.bat

# 4. Відкрийте у браузері
http://127.0.0.1:8000
⚙️ Помічник — це локальний застосунок (Python + FastAPI). Ця сторінка — презентаційний лендинг. Сам помічник працює у вас на комп'ютері, тож ваш ключ API нікуди не передається, окрім обраного провайдера ШІ.
